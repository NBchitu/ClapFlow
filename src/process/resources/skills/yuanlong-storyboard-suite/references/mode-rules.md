# Mode Rules

## Duration Branch
- Single-pass: duration < 180s
- Chain mode: duration >= 180s

## STC vs Faithful
- STC on: allow conflict arc / tension labeling
- Faithful on: keep source script 1:1; no narrative rewrite
- If conflict: faithful integrity wins

## Shot Count
- Auto: infer from duration + rhythm template
- Custom: exact hard lock

## Dialogue Lock
Keep extracted original dialogue verbatim in corresponding shots.
