# Parameter Effects

| Parameter | Effect on input | Effect on output |
|---|---|---|
| 核心情节输入 | Source text; may be sanitized | Main semantic source |
| 时长 | Controls mode and shot budget | Single vs chain, pacing |
| STC | No direct rewrite | Adds drama/tension structure |
| 保真模式 | Locks script to 1:1 visualization | Suppresses rewriting |
| 导演风格 | No direct rewrite | Injects style/camera/lighting constraints |
| 视觉风格 | No direct rewrite | Injects visual baseline/suffix |
| 镜数模式 | No direct rewrite | Hard-lock exact shot count |
| BGM/字幕 | No direct rewrite | Adds/removes markers |
| 词过滤 | Can replace/block terms | Safer phrasing |
| 素材标签开关 | No direct rewrite | Enforces @标签 consistency |
